# 2026 全季首杀结论 · 以及这些榜单有多少可信

数据：2026 VCT 全季 **15 个赛事 / 1,545 张图 / 32,786 回合 / 228,904 次击杀 / 63 支队伍 / 12 张地图**。
（Kickoff ×4 → 圣地亚哥大师赛 → Stage 1 ×4 → 伦敦大师赛 → Stage 2 ×4 → 上海冠军赛）

榜单口径：出场 ≥200 回合的 54 支队伍，共 64,513 个队伍-回合。区间为 Wilson 95%。

## 三、关键更新：数据翻倍之后，信度的排序变了

做法：把每支队伍的回合随机劈成两半、各算一遍指标，看两半名次相不相关。
上一版只有 15,715 回合，这一版是 32,786 回合（翻倍）。

| 指标 | 半样本 r | 全长修正 r | 上一版 | 判断 |
|---|---|---|---|---|
| **首杀率** | **+0.30** | **+0.46** | 0.60 | 仍然最稳 |
| **丢首杀后胜率** | +0.22 | **+0.36** | 0.13 | **从噪声变成可测** |
| **干净 4v5 翻盘率** | +0.24 | +0.39 | 0.10 | **同上** |
| 首杀转化率 | +0.11 | +0.21 | 0.11 | 略有改善，仍偏弱 |
| 多打少丢分率 | +0.06 | +0.10 | ≈0 | 仍是噪声 |

跨队标准差 2.33pp，纯二项期望 1.91pp，**过度离散 1.22×**（上一版 1.07×）。

### 这三件事值得说

1. **加数据确实提高了信度，但提高得不均匀。** 首杀率和转化率只小幅变化，
   而「丢首杀后胜率」和「4v5 翻盘率」从 0.1 跳到 0.36–0.39。
   也就是说：**逆风能力是这批指标里被样本量耽误得最厉害的一个**。
2. **「逆风能力」比「首杀转化率」更可测。** 听起来反直觉，但转化率的分母里混了经济、
   枪械、道具；逆风局反而更纯粹地取决于纪律和残局决策。
3. **「多打少丢分率」依然是纯噪声**（r≈0.10）。拿到人头优势还输掉这件事，
   在一个赛季的样本里分不出是队伍问题还是运气。

> 所以上一版我说「转化率完全是噪声」，现在要修正为：**它比噪声好一点，但还不足以排名**。
> 过度离散从 1.07 涨到 1.22，说明队间差异确实存在，只是样本还不够。

## 四、一个陷阱：和胜率的高相关是循环的

| 指标 | 与整体胜率的相关性 |
|---|---|
| 首杀率 | r = +0.76 |
| 首杀转化率 | r = +0.72 |
| 丢首杀后胜率 | r = +0.71 |
| 4v5 翻盘率 | r = +0.66 |
| 多打少丢分率 | r = −0.62 |

看着都很强。但这些指标**本来就是用同一批回合的胜负算出来的**——
一支队赢得多，它的转化率自然高。这不是预测力，是把胜率换个写法。

判断一个指标能不能评价队伍，要看它在时间上稳不稳（第三节），
不是看它和胜率相关多高。

## 五、四个站得住的画像

单个指标有噪声，但**几个相互独立的方向同时指向一处**，就值得当真。

### LEVIATÁN —— 顺风队

| | 数值 | 位置 |
|---|---|---|
| 首杀率 | **54.9%** | 第 2（且样本 1,608，最扎实） |
| 首杀转化 | **74.7%** | **第 1** |
| 丢首杀后胜率 | **28.2%** | 低于联赛 28.9% |
| 多打少丢分 | 22.5% | 略好于基准 24.4% |
| 整体胜率 | 53.7% | — |

**抢开局第一、兑现第一，但一旦丢了开局就回不来。**
对教练来说这是最好准备的一种队：把他的开局吃掉，他自己会崩。

### 100 Thieves —— 全面

| | 数值 |
|---|---|

| 首杀转化 | 73.4% |
| 丢首杀后胜率 | **33.9%**（联赛 28.9%） |
| 多打少丢分 | 22.9%（基准 24.4%） |
| 整体胜率 | **54.4%**（全样本最高档） |

四项都在好的一端，胜率也最高。这种队没有明显可打的点，只能靠执行。

### Fire Flux Esports —— 高方差

| | 数值 |
|---|---|
| 首杀率 | **57.7%**（第一） |
| 丢首杀后胜率 | **36.2%**（第一） |

抢开局最凶、逆风也能翻、拿到优势反而容易送。这不是「强」，是**每回合都在打对枪**。
把对枪拖成结构化回合，他的方差就会帮你。

### PCIFIC / ZETA —— 三项同时垫底

## 六、要把转化率测准，还差多少

单队首杀转化率的标准误约 `sqrt(0.71 × 0.29 / n)`。

- 现在每队 300–1,300 次首杀 → 95% 区间约 **±3pp**
- 想压到 ±1.5pp（能分出前十名内部顺序）→ 每队约 **3,600 次首杀**，是现在的 3 倍
- 按现在的赛程密度，大约还要 2–3 个赛季

---

## 七、这对建站意味着什么

1. **首杀率可以放心做排行榜**，它稳（r≈0.46），而且跨度大（15.4pp）。
2. **首杀转化率做排行榜要谨慎**：两端是真差别，中间是噪声。
   站点上已经按这个原则处理——表能排序，但底部写明了每一列的可信度。
3. **「逆风能力」现在可以拿出来了**（r≈0.36），但要标清楚它是半信半疑的水平。
4. **「多打少丢分 / 纪律性」不要写进文案**，r≈0.10，撑不住。
5. 真正值得深挖的是**回合内变量**：拿到首杀之后的经济、站位、有几个人、有没有道具。
   这些能解释「为什么转化率不一样」，而转化率本身不能。

## 八、跨赛段检验：整季榜到底能不能用（2026-10-26 新增）

上面的信度是「随机劈两半」——两半来自同一批比赛、同一个版本、同一批对手。
真实使用场景不是这样：教练想知道的是「第一赛段的数据能不能预测第二赛段」。
所以又做了一次更严格的检验：**用 S1 的指标去预测 S2**（同一批队、同一赛区）。

### 8.1 结果：能迁移的部分比想象中少

48 支队两个赛段各 ≥150 回合（转化率要求 ≥120 次首杀，所以是 41 支）。

| 指标 | S1 → S2 相关 | 判断 |
|---|---|---|
| 首杀率 | **+0.16** | 弱 |
| 丢首杀后胜率 | +0.27 | 弱 |
| 整体胜率 | +0.22 | 弱 |
| 首杀转化率 | **−0.12** | 反号，不可迁移 |

分赛区看首杀率（差异很大）：

| 赛区 | S1 → S2 r | 队数 |
|---|---|---|
| 中国 | **+0.47** | 12 |
| 太平洋 | +0.37 | 12 |
| 美洲 | +0.02 | 12 |
| EMEA | −0.01 | 12 |

中国赛区最稳，美洲和 EMEA 几乎完全不相关。可能的原因是中国队伍阵容变动小、
赛程结构一致；也可能只是样本量差异，不宜过度解读。

### 8.2 「进步 / 退步」有多少是假的

把每队的变化 Δ = S2 − S1 对 (S1 − 50) 做回归（首杀率全局恒为 50%，所以 50 是自然中心）：

- **斜率 = −0.84**（纯噪声 = −1.00，完全稳定 = 0.00）
- **约 40% 的变化方差可以由「S1 偏高就会回落」解释掉**
- 扣掉之后的残差标准差只剩 3.3pp

更直观的一个数：**S1 首杀率前 5 名的队，到 S2 只有 1 支还在前 5**（48 支队里纯随机也会中 0.5 支）。
前 16 名的重叠是 8/16，随机期望 5.3 —— 只有粗分组级别的一点点信号。

### 8.3 扣掉回归之后，真的变了的队

残差 = 实际变化 − 回归预期。正的说明「比回归预测的涨得更多」。

| 队伍 | S1 | S2 | 原始 Δ | 回归预期 | **残差** |
|---|---|---|---|---|---|
| Karmine Corp | 46.5% | 57.0% | +10.5 | +2.9 | **+7.6** |
| BBL Esports | 43.2% | 55.0% | +11.8 | +5.8 | **+6.1** |
| TYLOO | 51.9% | 56.1% | +4.1 | −1.6 | **+5.8** |
| Cloud9 | 43.5% | 53.0% | +9.5 | +5.5 | +4.0 |
| Gen.G | 48.9% | 53.7% | +4.7 | +0.9 | +3.8 |
| PCIFIC Esports | 45.2% | 39.8% | −5.4 | +4.0 | **−9.5** |
| FURIA | 48.1% | 43.3% | −4.7 | +1.6 | −6.4 |
| FNATIC | 52.7% | 45.0% | −7.8 | −2.3 | −5.5 |

注意 Paper Rex：S1 58.5% → S2 49.6%，看着掉了 8.9pp，但它在 S1 是全联盟第一，
按回归预期本来就该掉 3.4pp，**残差只有 −2.5pp**。它是「回到正常」而不是「崩了」。
FNATIC 相反：S1 只有 52.7（不算突出），掉到 45.0，残差 −5.5pp，是真的退步。

按「残差超过 1.96×标准误」算，**48 队里只有 2 支的变化在统计上站得住**
（跨全部赛区合并时）。分赛区更少：太平洋 0/12、中国 0/12。

### 8.4 所以整季数据该怎么看

**能用的地方：**
- 描述「这支队伍的打法风格」——抢不抢开局、首杀从谁手里出来、狙占多少
- 粗分组：前 16 / 中游 / 后 16 的划分比随机好一点
- 作为 scouting 的起点（先看整季，再切到具体赛事看当前状态）

**不能用的地方：**
- 预测下一赛段的表现
- 排「谁第 7、谁第 9」这种细排名
- 把「S1 → S2 涨了 11pp」当成进步

**结论一句话：整季榜是一张风格名片，不是实力预测器。**
站点的队伍表因此改成默认跟随赛事，整季降级成一个可切换的视角。

### 8.5 顺带解决了「阵容一致性」这一列

用户提出这一列没意义。实测支持这个判断：

| | 值 |
|---|---|
| 与胜率的相关 | **−0.25**（负的） |
| S1 → S2 跨赛段 | +0.45 |
| 实际范围 | 最高只有 44.5%（KRÜ），中位数 20% |

它测的其实是「这队带了几套阵容 / 打了几张图」——地图池越大，最常用阵容的占比必然越低，
跟打得好不好没关系，甚至因为输的队会换阵容而略呈负相关。**已从队伍表移除。**

替代它的是 **狙击首杀占比**（本队首杀里有多少是 Operator / Outlaw / Marshal 打的）：

| 指标 | 分半信度 | S1 → S2 | 与胜率 |
|---|---|---|---|
| **狙击首杀占比** | **0.91** | **0.81** | +0.21 |
| 首杀中位时刻 | 0.57 | 0.48 | −0.01 |
| 首杀集中度（队内第一人占比） | 0.56 | 0.41 | +0.08 |

狙击首杀占比跨赛段 r = 0.81，是全部候选指标里唯一「换赛段还基本不变」的。
它不预测胜负，但它是真正的打法指纹——对教练的含义很直接：占比高的队依赖狙击手架点，
烟掉那个位置就能压低他们的开局质量。首杀集中度也已用到球探页的 KPI 上。
