# 无畏契约赛事分析 · 项目说明

2026 VCT 全季 · 32,786 回合 · 1,545 张地图 · 15 个赛事 · 228,904 次击杀

一个能直接给教练组用的**对手队伍报告生成器**，加一个用来做基准的**全局分析站**。
数据全部来自 vlr.gg 的 2D 回放，不依赖任何官方 demo 文件。

---

## 一、为什么这条路走得通

Valorant 没有公开的 `.dem` 类回放文件，这是它和 CS 最大的数据差别。所以「做不了」是一个很常见的判断。

但 vlr.gg 的 2D replay 里其实有回合级的结构化数据：

| 有什么 | 粒度 | 覆盖 |
|---|---|---|
| 击杀流（击杀者/被杀者/英雄/武器/秒数/双方坐标/距离） | 每次击杀 | 228,904 次，79.6% 有坐标 |
| 买枪（每人武器/护甲/花费/剩余） | 每回合每人 | 12,497 回合，79.5% |
| 阵容（5 人英雄组合） | 每回合每队 | 中国赛区除外 |
| 回合结果（进攻方/防守方/胜方） | 每回合 | 100% |

**中国 VCT 赛区是明确的例外**：vlr.gg 上这些比赛的页面直接写
"No 2D replay available for this match"。同样在上海办的 2026 全球冠军赛却有完整回放。
所以中国赛区的 3,032 回合有击杀/英雄/武器/时间，**没有坐标也没有买枪数据**。
这不是抓取失败，页面本身就没提供。

> 结论：不做 demo 解析也能做到回合级分析，代价是没有逐帧位置与技能释放细节。

---

## 二、两个产出

### 1. 队伍报告生成器（`site/scout.html`，页面上叫「队伍报告」）

选一支队伍 + 一张地图，直接出一份对手准备文档：

- **三条可利用倾向**（自动从数据里挑出偏离联赛基准最大的三项，并按方向去重）
- 核心指标：回合胜率 / 首杀率 / 首杀→胜 / 首杀被补率 / 阵容一致性 / Meta Fit
- 阵容指纹：最常用的 5 套 5 人阵容与占比
- 经济结构：按实际持有的长枪数分三档，各档占比与胜率
- 手枪局与第 2 局：进攻/防守分手枪胜率，输手枪后的买法分布
- 攻防分侧：同一批回合按进攻/防守拆开的胜率、首杀率、首杀转化
- 谁在开火：球员级首杀数、占队内比例、每 10 回合频率、主用英雄
- 首杀时刻分布、首杀后能不能赢（被补 vs 没被补）

每个数字都带 n；n < 40 标「小样本」，n < 20 直接降透明度。中国赛区会显示
「无经济数据 / 无坐标数据」，部分覆盖会显示具体百分比而不是悄悄算平均。

### 2. 全局基准站（`site/index.html`）

把「一次首杀值多少钱」这件事拆开：按武器、按攻防、按时间、按赛事、按队伍。
用来给球探报告提供参照系（例如全季首杀→胜是 71.0%，不是 50%）。

## 三、三个方法论判断（这部分才是项目重点）

### 判断一：补枪效应是真的，不是经济差装出来的

原始结论：首杀被补掉，胜率从 75.7% 掉到 56.9%，差 18.8pp。这是全数据最强的单变量。

但有一个显然的替代解释：**经济差的回合更容易被打成补枪**，所以「补枪」可能只是「没钱」的影子。
把首杀方按买枪分档后重算：

| 首杀方买枪 | 被补→胜 | 没被补→胜 | 差 |
|---|---|---|---|
| eco | 44.0% (n=1,383) | 60.0% (n=3,251) | **+16.0 pp** |
| 半买 | 65.3% (n=608) | 79.7% (n=1,707) | **+14.4 pp** |
| 全买 | 60.2% (n=4,364) | 78.5% (n=14,515) | **+18.3 pp** |

同经济层内差距 14.4–18.3pp，方向一致。**补枪是真效应，不是混杂。**

> 注：这里的「eco」指「队里 ≤1 把长枪」，不是「存钱」。实测这一档里 12% 是
> 4 把以上 Stinger / Spectre 的强起。分层结论不受影响（三档都同向），
> 但这个名字在页面上已经删掉了，见 `DESIGN.md` 第八节。

### 判断二：买枪强度不能用「花了多少钱」来量

第一版我用 `spent`（本回合花费）分档，算出「全买 vs eco 只有 54.8%」。
这个数不对——一个满配队伍打 eco 应该赢八成以上。查了具体回合：

```
XLG (Sheriff / Marshal / Bandit / Sheriff / Bandit)  spent 7,500
NRG (Vandal / Phantom / Outlaw / Phantom / Vandal)  spent 7,850
```

NRG 五人端着长枪，但「花费」只有 7,850 —— 因为枪是**上回合保下来的**。
赢了上一回合、留枪进下一回合，花费接近 0，但那是满配不是 eco。

**花费量的是「这次补了多少」，不是「现在有多强」。**
改用实际持有的长枪数（Vandal / Phantom / Guardian / Bulldog / Odin / Operator / Outlaw / Marshal）：

| 我方 vs 对手 | n | 回合胜率 |
|---|---|---|
| 全买 vs eco | 4,961 | **80.0%** |
| 全买 vs 半买 | 2,723 | 62.2% |
| 全买 vs 全买 | 27,886 | 50.0% |
| 半买 vs 全买 | 2,723 | 37.8% |
| eco vs 全买 | 4,961 | **20.0%** |

干净、单调，而且和公开研究对上了（见下）。

顺带验证了这个字段本身没记错：**手枪局长枪率 0.0%**，第 3 局 78.8%，第 5 局 81.4%。
如果 `weapon` 记的是回合结束时的状态，第 1 局不可能一把长枪都没有。

### 判断三：拿首杀不等于拿到优势，得看你拿首杀时有多穷

按「首杀方买枪 vs 对手买枪」拆开首杀转化率：

| 首杀方 | 对手 | n | 首杀→回合胜 |
|---|---|---|---|
| 全买 | eco | 3,385 | **88.9%** |
| 半买 | eco | 1,117 | 93.2% |
| 全买 | 半买 | 1,551 | 78.7% |
| 全买 | 全买 | 13,943 | 70.3% |
| eco | 全买 | 1,576 | **39.0%** |
| eco | 半买 | 421 | **28.7%** |

**拿首杀但经济落后，胜率不到四成。** 这一条现在的页面上说不出，因为页面的首杀统计
一直把「谁拿了首杀」和「拿的时候什么装备」混在一起。

## 四、外部对标：用 32,786 个职业回合复核一份 1.45 亿回合的公开研究

Northeastern 的 Roux Institute 用 Omnic 的比赛数据做过四个独立分析
（145,456,352 回合 / 7,000,653 场比赛），公开了具体数字。
职业比赛和全rank 数据不是一回事，但结论应该同向——**不同向就说明我的实现有问题**。

`95_replicate_study.py` 逐条对照：

| 指标 | 本项目（VCT 职业） | Roux / Omnic（全段位） | 差 |
|---|---|---|---|
| 首杀→回合胜 | 71.05% | 68.58% | **+2.47 pp** |
| 全买 vs eco | 80.0% | 85.0% | −5.0 pp |
| eco vs 全买 | 20.0% | 15.9% | +4.1 pp |
| 手枪局赢家拿下第 2 局 | 87.7% | ~80% | +7.7 pp |
| 手枪局输家拿下第 3 局 | 59.1% | ~60% | −0.9 pp |
| 手枪局买护甲 | 15.7% | 16.67% | **−1.0 pp** |
| 手枪局买 Ghost | 48.9% | 41.8% | +7.1 pp |

七项里五项同向同量级。两个值得说的差：

- **首杀价值高 2.5pp**：职业队更会兑现人数优势，残局纪律更好。合理。
- **手枪局护甲 15.7% vs 16.67%**：差不到 1 个百分点。这个数本身没什么用，
  但它证明我的买枪字段解析是对的——如果解析错了，不可能在这么细的分布上撞上。

**一处没复现**：他们的首杀效应跨九张图的极差只有 0.58pp，我这里 3.76pp。
不是结论错，是样本量差 1000 倍：他们每张图约 1,460 万回合，我每张图约 1,500 回合。
按这个样本量，3.76pp 的极差完全在噪声范围内。**不能因此说「职业赛地图差异更大」。**

## 五、诚实的局限

1. **没有下包位置**。`boom_at` 只有 9.9% 覆盖，做不了「A 点 vs B 点」和「包点位置转化率」。
   这是 Roux 那份研究里最强的一条（Ascent A 点最强/最弱位置差 16pp），我这里做不了。
2. **没有技能释放**。所以「道具效率」「开局投掷」这类分析全部缺失。这是 vls 级数据才有的。
3. **中国赛区缺坐标与买枪**，3,032 回合（19%）只能进表格，不能进热力图与经济分析。
4. **阵容一致性/ Meta Fit 不含中国赛区**（该赛区不提供 5 人阵容）。
5. **样本量**：单队单图经常只有 100 回合上下。页面标了小样本，但结论仍要谨慎。
6. **对手准备的真实前提是「对手不知道你在研究他」**，职业队的 anti-strat 会故意放假动作，
   公开比赛数据里的倾向可能本身就是设计过的。

## 六、对照：真实分析师在做什么，这个项目做到哪一步

公开资料里，战队分析师的日常工作大致是：
翻 10–20 场对手 VOD，在每张图上标 30–50 个重复执行的战术，
折算成几个简单指标（进点成功率、回合前道具使用、平均回合时长、2 秒内补枪率），
然后挑出 2–3 条最可利用的倾向，拿去训练赛验证。

| 分析师做的事 | 本项目 | 缺口 |
|---|---|---|
| 对手倾向识别 | ✅ 自动生成 top 3 | 靠统计偏离，不是看录像 |
| 买枪/经济决策 | ✅ 手枪局、第 2 局、三档买枪 | 没有「该不该 force」的决策建议 |
| 球员角色与开火点 | ✅ 首杀者排行 + 英雄池 | 没有逐帧站位，说不出「他总在这条线」 |
| 进点成功率 / 包点 | ❌ | 缺下包坐标 |
| 道具使用 | ❌ | 缺技能释放数据 |
| 训练赛验证 | ❌ | 这是战队内部才有的一环 |

所以这个项目能替代的是「第一小时的筛数据」，替代不了「看录像 + 训练赛验证」。
我在文档里不把它说成「AI 分析师」。

把对手首杀被补的回合也算进了本队统计。

## 八、下一步

按「对教练有用」排序：

1. **补下包坐标**——如果能从别的地方拿到，A/B 点与包点位置分析立刻能做，
   这是目前最大的能力缺口。
2. **球探报告导出成单页 PDF**，直接进教练组的赛前包（页面已支持 `window.print()`）。
3. **对手对比模式**：我方 vs 对手同图同指标的并排，现在只能一次看一队。
4. **跨赛事漂移**：伦敦（6 月）到三个赛段（7–9 月）之间，「谁在拿首杀」已经翻了一倍
   （霓虹 10.2% → 19.7%，捷风 17.0% → 7.1%），但转化率没动。这个版本差异值得单独做一页。
5. **队伍级反补刀能力**：按队伍算「首杀没被补比例」减去「丢首杀时被补比例」，
   和胜率相关 r=+0.33（n=54），比 Meta Fit 强十倍。现在只在 `RESULTS.md` 里，没进页面。
